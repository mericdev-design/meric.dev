# Meric.dev V2

Refonte complète du site Meric.dev avec une direction visuelle inspirée des principes d'interface Apple modernes : surfaces translucides, hiérarchie typographique, grands rayons, profondeur légère et responsive mobile-first.

## Notes
- Les polices Apple SF fournies par l'utilisateur ne sont **pas redistribuées** dans ce dépôt. Le CSS utilise la pile système Apple (`-apple-system`, `BlinkMacSystemFont`) avec des fallbacks web sûrs.
- Le formulaire conserve l'endpoint Formspree de la version précédente.
- Remplacer la clé `data-sitekey` reCAPTCHA factice dans `index.html` par la clé publique réelle du domaine avant production.
- Tester les URLs de projets avant mise en production.
